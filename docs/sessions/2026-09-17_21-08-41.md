### 解决思路
1. **先核实仓库真实信息，不照抄外部文本**：`git config` 作者 = `ZJX / 1363343773@qq.com`，

2. **必须改写的差异点**：
   - 技术栈：参考文本是 Dart/Flutter + C++（audioplayers / sqlite3 / path_provider），
     本仓库是 Python 生态 → 第三方组件声明整段重写，并给出真实依赖清单来源

   - 「本软件」定义：改为真实资产 —— `crawler_api.py`、`crawler_core/`、`tool/`、`legacy/`、`test/`、
     `tjc_hymn.db` 建表/迁移逻辑、`crawler_core/naming.py` 命名真源，以及原创算法

   - **PyMuPDF 为 AGPL-3.0**：与「保留所有权利」的自有许可存在冲突风险，必须在第三方声明中显式提示，

     API Key 自备自管、抓取责任自负、输出物对外发布前须自查素材授权、境外网络环境合规）。
4. **形态取舍**：`LICENSE` 保持与参考文本同构（纯文本 + `----` 分节线，无 Markdown 语法依赖），
   章节 = 授权范围（个人学习与参考 / 禁止商业使用 / 禁止的行为 / 用户数据与个人状态）
   → 第三方组件与素材声明 → 数据来源与合规使用 → 商业授权 → 免责声明 → 权利保留与适用法律 → 页脚署名。
5. **一致性收尾**：项目「根目录只保留 `README.md` / `crawler_api.py` / `tjc_hymn.db`」的约定在
   `.clinerules`、`README.md`、`docs/SESSION_SUMMARY.md` 三处均有表述 → 一并补入 `LICENSE`，避免文档自相矛盾。
