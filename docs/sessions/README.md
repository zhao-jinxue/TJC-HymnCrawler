# 会话开发日志（Cline 开发记录）

本目录用于记录使用 **Cline Agent** 开发 hymn_crawler 的每一次会话历程，包括提问、解决思路、最终结果，形成可回溯的开发档案。

## 目录规范

| 文件/目录 | 说明 |
| --- | --- |
| `YYYY-MM-DD_HH-MM-SS.md` | 每个会话一个日志文件，以**会话开始时间**命名（精确到秒） |
| `_template.md` | 日志模板，新会话复制此文件填写 |
| `README.md` | 本说明文件 |

## 命名规则

- 格式：`YYYY-MM-DD_HH-MM-SS.md`（会话开始时间，24 小时制）
- 同一秒冲突时追加后缀：`YYYY-MM-DD_HH-MM-SS_2.md`、`_3.md` 依次递增
- 示例：`2026-08-18_21-15-00.md`

## 日志结构（强制）

每个日志必须包含以下章节（可多任务分段）：

```markdown
# <会话主题>

- 日期：<YYYY-MM-DD>
- 工具链：Cline
- 涉及模块：<可选>

## 任务 1：<任务标题>

### 提问
（用户初始提问与后续追问的要点记录）

### 解决思路
（动手前的分析结论、可选方案、选定方案与理由）

### 最终结果
（完成结论、关键改动文件清单、验证方式、遇到的困难、遗留问题）

---

## 任务 2：<任务标题>
...

## 会话总结
（本次共处理 N 个任务，关键收获，遗留事项）
```

## 质量要求

1. 只记录**有价值的决策与结论**，避免工具调用流水账
2. 提问记录保持用户原意，技术细节可简写
3. 结果记录必须包含三要素：**改了什么文件 / 验证了什么 / 遗留什么**
4. 日志随代码一起 `git add docs/sessions/` 提交，成为项目历史的一部分
